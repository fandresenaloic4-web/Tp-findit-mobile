Technologies à utiliser
Ionic Vue + TypeScript pour l’interface mobile.

Firebase Authentication pour les comptes.

Cloud Firestore pour les annonces et les profils.

Firebase Storage pour les photos.

Capacitor Camera pour prendre ou choisir une photo.

Capacitor Geolocation seulement dans la Version 2.

Android Studio pour compiler, tester et générer l’APK.

Mon conseil
Fais FindIt, mais commence par une version simple :

Crée l’interface : accueil, publication, détail, profil.

Ajoute Firebase Authentication.

Enregistre les annonces dans Firestore.

Ajoute l’upload de photos avec Firebase Storage.

Ajoute la recherche et les filtres.

Ajoute le changement de statut.

Ensuite seulement, ajoute la carte, le GPS et le chat.

C’est un très bon choix de projet : il est utile, compréhensible, visuel et assez complet pour montrer tes compétences en Firebase, Firestore, Ionic, Vue et Android. Il est plus intéressant qu’une application de tâches, tout en restant accessible si tu le construis par étapes.
